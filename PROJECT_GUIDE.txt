PROJECT OVERVIEW
----------------
Name:        AgriVision AI
Purpose:     Crop disease detection and intelligent alerts
Stack:       Python 3.12, OpenCV 5, TensorFlow, FastAPI, AWS (optional)
Author:      Hamrit Mohamed Lamine (mohamedhamrit)
Competition: OpenCV AI Competition 2026 — Agentic Vision track

The system analyzes smartphone video of crops, segments leaf/plant
regions using OpenCV HSV transformations, detects disease lesions,
grades severity (healthy/mild/moderate/severe), classifies the
disease with a MobileNetV2 CNN, and triggers agentic actions
(no-action, log, email alert, urgent SNS+SES alert).

------------------------------------------------------
PHASE 1: PROJECT CREATION
------------------------------------------------------

1.1 Create project folder
    mkdir my-project
    cd my-project

1.2 Initialize Python virtual environment
    python -m venv venv
    venv\Scripts\activate          (Windows)
    source venv/bin/activate       (Mac/Linux)

1.3 Install dependencies
    pip install <your-packages>
    pip freeze > requirements.txt

1.4 Create project structure
    my-project/
    ├── my_project/
    │   ├── __init__.py
    │   ├── app.py              (web endpoint)
    │   ├── models.py           (data models)
    │   ├── core/               (main logic)
    │   ├── tests/
    │   │   └── test_main.py
    │   └── requirements.txt
    ├── deploy/
    │   ├── Dockerfile
    │   └── README.md
    ├── sample_data/            (if needed)
    ├── .gitignore
    ├── README.md
    └── render.yaml             (if deploying to Render)

1.5 Create .gitignore FIRST (before any code)
    Common entries:
    __pycache__/
    *.pyc
    *.pyo
    venv/
    .venv/
    .pytest_cache/
    .vscode/
    .idea/
    *.egg-info/
    dist/
    build/
    .DS_Store
    Thumbs.db
    *.tmp
    *.log

------------------------------------------------------
PHASE 2: GIT SETUP & GITHUB
------------------------------------------------------

2.1 Install Git (if not installed)
    Download: https://git-scm.com/downloads
    Verify:   git --version

2.2 Install GitHub CLI (if not installed)
    Download: https://cli.github.com/
    Verify:   gh --version

2.3 Configure git identity (ONE TIME ONLY)
    git config --global user.name "your-username"
    git config --global user.email "your-email@example.com"
    NOTE: Use the email from your GitHub account.

2.4 Login to GitHub CLI
    gh auth login
    - Choose: GitHub.com
    - Choose: HTTPS
    - Choose: Login with web browser
    - Copy the one-time code
    - Open the URL in browser
    - Paste the code and authorize

2.5 Verify login
    gh auth status

2.6 Initialize git repo
    cd my-project
    git init

2.7 Add and commit
    git add .
    git status                  (ALWAYS CHECK before commit)
    git commit -m "Initial commit - description of project"

2.8 Create GitHub repo and push (ONE COMMAND)
    gh repo create my-project-name --public --source=. --push
    
    This creates the repo on GitHub AND pushes in one step.
    
    For private repo:
    gh repo create my-project-name --private --source=. --push

2.9 Your repo URL is now:
    https://github.com/your-username/my-project-name

------------------------------------------------------
PHASE 3: COMMON ISSUES & FIXES
------------------------------------------------------

ISSUE 1: "Author identity unknown" when committing
FIX:    git config user.name "your-username"
        git config user.email "your-email@example.com"

ISSUE 2: "gh: You are not logged into any GitHub hosts"
FIX:    gh auth login
        Follow browser prompts.

ISSUE 3: Large files making repo too big
FIX:    Add to .gitignore BEFORE committing:
        - Generated datasets (*.png, *.jpg in output folders)
        - Model files if too large (>50MB)
        - Videos, binaries
        
        For files already tracked:
        git rm --cached <large-file>
        git commit -m "Remove large file from tracking"

ISSUE 4: Push rejected (remote has content you lack)
FIX:    git pull --rebase origin main
        git push

ISSUE 5: Wrong branch name (main vs master)
FIX:    Check current branch:
        git branch
        
        Rename if needed:
        git branch -m master main

ISSUE 6: Need to update repo after changes
FIX:    git add .
        git commit -m "Description of changes"
        git push

------------------------------------------------------
PHASE 4: WEB DEPLOYMENT (RENDER.COM)
------------------------------------------------------

4.1 Create render.yaml in project root
    services:
      - type: web
        name: my-project
        runtime: python
        buildCommand: pip install -r requirements.txt
        startCommand: uvicorn app:app --host 0.0.0.0 --port $PORT
        envVars:
          - key: PYTHON_VERSION
            value: "3.12"

4.2 Push to GitHub (if not already)
    git add render.yaml
    git commit -m "Add Render deployment config"
    git push

4.3 Deploy on Render
    a) Go to https://render.com
    b) Sign up / Log in with GitHub
    c) Click "New +" → "Web Service"
    d) Connect your repository
    e) Fill in:
       - Name: your-project-name
       - Runtime: Python
       - Build Command: pip install -r requirements.txt
       - Start Command: uvicorn app:app --host 0.0.0.0 --port $PORT
       - Python Version: 3.12
    f) Click "Create Web Service"
    g) Wait 5-10 minutes for build + deploy

4.4 Your endpoint URL:
    https://your-project-name.onrender.com

4.5 Verify deployment:
    curl https://your-project-name.onrender.com/health

PHASE 6: CREATING ZIP FOR SUBMISSION
------------------------------------------------------

6.1 Don't include:
    - __pycache__/ folders
    - .pytest_cache/ folder
    - .git/ folder
    - venv/ or .venv/ folder
    - Generated datasets (if regeneratable)
    - Large binary files not needed

6.2 Windows PowerShell method:
    # Exclude specific folders
    $source = "C:\path\to\project"
    $dest = "C:\path\to\project.zip"
    
    # Use a staging folder approach
    $staging = "$env:TEMP\zip-staging"
    New-Item -ItemType Directory -Path $staging -Force
    
    # Copy with exclusions using robocopy
    robocopy $source $staging /E /XD __pycache__ .pytest_cache .git venv .venv dataset videos /XF "*.pyc" /NFL /NDL /NJH /NJS
    
    # Create zip
    Compress-Archive -Path "$staging\*" -DestinationPath $dest -Force
    
    # Cleanup
    Remove-Item $staging -Recurse -Force

6.3 Check zip size before submitting
    (Get-Item $dest).Length / 1MB
